# Design Process

## Engineering Design Approach

The design process follows an iterative engineering methodology:

1. Define system requirement specifications
2. Select appropriate hardware components
3. Develop prototype systems
4. Validate and test system components
5. Design a custom PCB
6. Integrate hardware and software systems
7. Perform flight testing
8. Review and analyze collected results

## Design Challenges and Considerations

Key design considerations include:

- Mass constraints
- Energy requirements
- Sensor characteristics and limitations
- Physical integration constraints
- Reliability concerns related to electrical components
- Data storage and logging requirements

## Major Roadblocks

The following represent significant challenges encountered during the design process:

- Integrating multiple sensors into a compact avionics package
- Developing a reliable distributed electrical system
- Maintaining accurate measurements during flight conditions
- Designing and manufacturing a PCB suitable for aerospace applications
