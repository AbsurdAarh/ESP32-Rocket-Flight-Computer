# Project Overview

## Introduction

The ESP32 Rocket Flight Computer is an avionics system designed to acquire and process flight data from model rockets.

This project draws on concepts from embedded systems, electrical engineering, PCB design, and aerospace engineering to develop a compact avionics computer.

## Motivation

Autonomous sensing and control systems are used in modern aerospace vehicles, from aircraft to spacecraft. The goal of this project is to explore the fundamental engineering principles behind these systems through the development of a miniature flight computer.

## Objectives

The system is designed to:

- Build custom hardware
- Record flight data
- Develop embedded systems skills
- Design a well-engineered PCB
- Apply engineering principles toward a practical aerospace application

## System Features

The flight computer is designed to record:

- Altitude
- Orientation
- Acceleration during flight
- Local environmental conditions
- Time data
