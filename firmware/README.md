# Firmware

This folder contains the embedded software for the ESP32 flight computer.

## Responsibilities

The firmware is responsible for the following functions:

- Sensor communication
- Sensor data processing
- Sensor data logging to the SD card
- Flight computer operation

## Development Environment

The firmware is developed using:

- C++
- Arduino IDE
- ESP32 Arduino Framework

## Folder Structure

- **src/** – Main firmware source files
- **include/** – Header files, configuration files, and shared definitions
