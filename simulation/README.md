# Simulations

This folder contains simulation files used during the design and development process of the ESP32 Rocket Flight Computer and its associated rocket system.

These simulations were created to investigate and analyze system performance before manufacturing hardware prototypes and conducting real-world testing.

## Contents

- OpenRocket simulations
- CAD models
- Design validation files

## Purpose

Simulation allows the evaluation of rocket performance, stability, and design decisions before physical construction and flight testing.

These tools help identify potential issues and optimize the design prior to real-world implementation.
